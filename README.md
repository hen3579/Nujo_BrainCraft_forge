# Nujo's Braincraft[怒九的脑洞世界]

## Mod介绍

也许你说的没错，这确实是一个比较偏粉丝向的模组。

不过这个项目除了记录一些视频里出现的设定、细节或者彩蛋之外，也有一篇属于自己的故事，一篇关于梦境和现实反复交互的故事……

作为玩家的你，很感谢你能来一起见证这样的世界诞生，以及变化……
### 剧情介绍
#### 序章



#### M01-画笔与异世界

在进入这个新世界后，你发现似乎里面比想象中动荡的厉害不少。有一群穿着黑色西装，带着武器的人与毛茸茸的有着黑色翅膀的”怪物“互相厮杀，还有……，有一个浑身穿着品红色的人，对你进入这个世界的画笔垂涎已久，于是安排了自己的手下去”追杀“你，而你也在不得已的情况下与品红色的她展开了战斗。

#### M02-偏见与压力

从与脑精的战斗中，你得知了她并没有想对你痛下毒手的意思，她只是很想要你手里的笔而已，想追杀你的另有其人，不仅如此，脑精也感觉到自己在这片大陆里有一种被架空的感觉，好多发生在宫殿外的事自己并不知道。于是你们决定联手，把目光转移到那群黑衣人，经过一番推理和调查，你找到了这些日子里制定和执行着”逐杀令“的主使——黑衣兵团的统帅”黑西“，在指控了他的恶意教唆杀害异魔族群，等一系列罪行之后，便与他进行了战斗。
