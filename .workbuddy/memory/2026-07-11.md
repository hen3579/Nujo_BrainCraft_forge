# 2026-07-11 工作日志

## NujoThinker 行走动画修复
- 问题: `isMoving()` 使用 `getNavigation().isInProgress()` 和 `xxa/zza` 检测移动状态，但这些在客户端永远为 false/0，导致行走动画不播放
- 修复: 改为 `this.getDeltaMovement().horizontalDistanceSqr() > 1.0E-6` 基于速度检测，客户端可正确获取
- 文件: `src/main/java/com/Hen3579/Nujomod/Entities/NujoThinker/NujoThinkerEntity.java`

## Blockbench 实体建模咨询
- 项目使用 GeckoLib 4.4.9，Blockbench 中推荐选 "GeckoLib Animated Model"（需装插件）或 "Bedrock Entity"
- 两者底层格式相同，导出 3 个文件: `.geo.json` + `.animation.json` + `.png`
- 放置路径: `assets/nujobraincraft/geo/entity/`、`animations/entity/`、`textures/entity/`
- Java 类参照 NujoThinker: Entity extends PathfinderMob implements GeoEntity, Model extends DefaultedEntityGeoModel, Renderer extends GeoEntityRenderer
