# 2026-07-06

## 修复鸟瞰视角无法攻击滞空生物的问题

### 问题根因
`ClientEventHandler.updateHoveredBlock()` 中实体检测**依赖于方块命中检测结果**：
1. 实体检测代码写在 `if (blockHit.getType() == HitResult.Type.BLOCK)` 内部——光标指向天空时跳过实体检测
2. 检测框只覆盖地面以上 4 格范围，滞空/飞行生物的包围盒不包含地面命中点

### 修改内容

**`ClientEventHandler.java` — `updateHoveredBlock()`**
- 将实体检测与方块检测解耦：新增独立于方块检测的实体搜索逻辑
- 沿光标 XZ 位置发射垂直射线，在**全高度范围**搜索实体（从世界最低 Y 到相机上方）
- 实体命中优先级高于方块（光标下同时有方块和实体时，显示实体高亮）
- 使用 `entity.getBoundingBox().inflate(0.25)` 提高小实体容错

**`ClientEventHandler.java` — `handleClickToAttack()`**
- 新增攻击距离检查：近程（≤4.5格生存/6格创造）直接攻击，远程自动走向目标
- 远程攻击时设置自动追击目标到 `BirdviewClientEvent`

**`ClientEventHandler.java` — `handleMoveToTarget()`**
- 新增自动追击逻辑：接近攻击目标至攻击范围内时自动执行 `attack() + swing()`
- 目标移动时实时更新移动目标位置

**`BirdviewClientEvent.java`**
- 新增 `attackTarget` (LivingEntity) 字段及相关 getter/setter
- `reset()` 和 `clearMoveTarget()` 同步清除攻击目标

### 影响范围
- 修改了 2 个文件：`ClientEventHandler.java`、`BirdviewClientEvent.java`
- 编译通过，无新增错误/警告

## 新增鸟瞰视角移动痕迹系统

### 功能
右键点击地面移动时，在目标位置留下**变色高亮环**标记，持续 3 秒后消失。

### 痕迹视觉效果
- **内环**（固定半径 0.4 格）：纯色环，完整透明度
- **外环**（半径从 0.4 扩大到 1.0）：半透明外扩环
- **颜色渐变动画**：绿(新生) → 黄(中期) → 红(即将消散)
- **淡出**：后 30% 时间透明度逐渐归零

### 修改文件
| 文件 | 改动 |
|------|------|
| `Client/Events/BirdviewClientEvent.java` | 新增 `MoveTrail` record、痕迹列表、`addMoveTrail()` / `getActiveMoveTrails()` / `clearMoveTrails()`；`reset()` 同步清痕迹 |
| `Client/Events/ClientEventHandler.java` | `handleClickToMove()` 中调用 `addMoveTrail()`；`onRenderLevelStage()` 中新增痕迹渲染循环；新增 `drawGroundRing()` 辅助方法绘制地面圆环 |
