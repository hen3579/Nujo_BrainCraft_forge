### [Fix] 鸟瞰模式左键点不到空中怪物

**问题诊断**：鸟瞰模式下空中实体检测依赖渲染阶段（`RenderLevelStageEvent.AFTER_ENTITIES`）缓存的投影矩阵和相机数据（`getCachedCameraPos` + `worldToScreen`），但悬停检测在 tick 阶段（`ClientTickEvent.Phase.END`）执行，导致：
1. 首帧缓存为 null，整个屏幕空间拾取被跳过
2. `worldToScreen` 在任何缓存值为 null 时静默返回 null，无报错
3. 缓存的投影矩阵可能被内部重置为透视矩阵，导致投影坐标错误

**修复方案**：用纯数学投影替代缓存依赖
- `BirdviewClientEvent.worldToScreenPureMath()` — 新方法，使用 `zoom`、`fixedYaw`、`cameraLookPitch`、玩家位置做纯三角函数投影，是 `screenPosToWorldPos` 的精确逆运算
- `ClientEventHandler.updateHoveredBlock()` — 空中实体检测改用 `worldToScreenPureMath`，搜索范围以玩家位置为中心，深度比较也用玩家位置
- 零缓存依赖，首帧即可使用，消除了所有时序问题和静默失败

**数学验证**：正交投影下世界→屏幕是线性映射，相机右轴 `(cos(yaw), 0, sin(yaw))` 和上轴 `(sin(yaw)*sin(pitch), cos(pitch), -cos(yaw)*sin(pitch))` 可纯三角推导，与 `screenPosToWorldPos` 使用完全相同的坐标轴定义，互为逆运算。

**编译结果**：`compileJava` 成功（仅剩 3 个原有 deprecation 警告）

**修改文件**：
- `src/main/java/com/Hen3579/Nujomod/Client/Events/BirdviewClientEvent.java` — 新增 `worldToScreenPureMath` 方法
- `src/main/java/com/Hen3579/Nujomod/Client/Events/ClientEventHandler.java` — `updateHoveredBlock` 中空中实体检测替换为纯数学方案

### [Fix] 远程攻击跨线程崩溃 — LegacyRandomSource

**问题**：鸟瞰模式下弓远程攻击时游戏崩溃，`Accessing LegacyRandomSource from multiple threads`。`LockTargetSystem.fireBowOnServer` 在客户端 tick 线程直接调用 `serverPlayer.releaseUsingItem()`，而 `BowItem.releaseUsing()` 内部访问服务端世界的 `LegacyRandomSource` 随机数生成器，1.20.1 的 `ThreadingDetector` 检测到跨线程访问直接崩溃。

**根因**：`fireBowOnServer` 用 `server.execute(lambda)` 把弓释放逻辑排队到服务端线程。但调用方 `tickBowCharging` 在 `fireBowOnServer()` 返回后立刻执行 `rangedTarget = null`。等服务端线程执行 lambda 时，`rangedTarget` 已为 null → `calculateBallisticAim(sp, null, ...)` 抛 NPE → 箭矢永远不生成。弩/三叉戟/投掷物不受影响（直接执行，用参数 `target` 而非静态字段）。

**修复**：在 lambda 之前用 `final Entity target = rangedTarget` 捕获到局部变量，lambda 内用 `target` 而非 `rangedTarget`。增加 `!target.isAlive()` 安全检查。

**修改文件**：`LockTargetSystem.java` — `fireBowOnServer` 方法
