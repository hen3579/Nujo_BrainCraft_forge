### [Fix] 弓不发射 + 近战失效

**弓不发射根本原因**（2 个bug）：
1. `mc.gameMode.releaseUsingItem()` 只 `send()` 包，不调 `player.releaseUsingItem()` 本地停止动画 → 客户端永远卡在蓄力。
2. `handleEndPhase` 在 `rangedTick` 之后立即 `setXRot(0)` → 服务端处理 RELEASE_USE_ITEM 包时 player.getXRot() = 0 → 箭水平飞出。

**修复**：
- `tickBowCharging` 释放时：`faceEntityForRanged` → 发包 → **`player.releaseUsingItem()` 本地停止**
- 新增 `skipPitchReset` 标志 → 释放当 tick 跳过 pitch 重置，让服务端读到正确瞄准角度
- `handleEndPhase` 检查 `shouldSkipPitchReset()` 再决定是否重置 pitch

**近战失效原因**：
- `tryRangedAttackOnHover` 对非远程武器返回 false，但左键已被消费吞掉。
- 备份中的 `handleClickToAttack` 没有被合并进来。

**修复**：
- 统一入口 `tryAttackOnHover(mc)`：远程武器→远程；近战/空手→近战
- 近战逻辑直接从备份 `handleClickToAttack` 迁移：`faceEntity` + `mc.gameMode.attack()` + `swing()`

### [Fix] 追杀致死不触发

**根因**：`startMeleeChase` 从未被任何调用方触发，`chaseTick` 因 `isChasing==false` 直接 return。
**修复**：
- `toggleLock()`→`lockToTarget(nearest)` 后追加 `startMeleeChase(mc, nearest)`，Tab 锁定即追杀
- `tryMeleeAttack()` 中如果目标未锁定且为敌对生物 → 自动锁定+开启追杀；如果已锁定但未追杀 → 开启追杀

### [Fix] 弓显示蓄力取消

**根因**：vanilla `handleKeybinds()` 检测到 `keyUse` 未按住，会在每 tick 中自动释放弓物品（调用 `releaseUsingItem`），导致 `isUsingItem()` 始终为 false，蓄力被反复取消。

**修复方案**：不再依赖客户端的 `isUsingItem()` + `gameMode` 包流程蓄力。
- `tickBowCharging` 不再检查 `isUsingItem()`，独立计数 `bowChargeTicks`
- 蓄力完成后直接调用 **集成服务端** 的 `serverPlayer.releaseUsingItem()`（绕过 handleKeybinds 干扰）
- `fireBowOnServer()`：
  1. 通过 `mc.getSingleplayerServer()` 拿到 ServerPlayer
  2. 将客户端的旋转（yaw/pitch/bodyRot）同步到 ServerPlayer
  3. 反射设置 `useItemRemaining = 0` → `BowItem` 读到满蓄力 power=1.0
  4. 调用 `serverPlayer.releaseUsingItem()` → 服务端生成满力箭矢
- 联机模式退回到包模式 `gameMode.releaseUsingItem()` + `player.releaseUsingItem()`

### [优化] 其他远程武器弹道修正

**问题**：弩、三叉戟、雪球等即时发射武器，同样会因 `handleEndPhase` 重置 pitch=0 而水平飞出。

**修复**：
- `tryRangedAttack` 重构：弩/三叉戟/投掷物 → 统一走 `fireInstantOnServer()`
- `fireInstantOnServer()`：同步旋转到 ServerPlayer + 直接调 `serverPlayer.gameMode.useItem()` 在服务端生成弹射物
- 设置 `skipPitchReset = true` 保护本 tick 的 pitch
- 保留 packet fallback（联机环境）
- 弩未上膛时强制满充能 + 立即发射（跳过 vanilla 25 tick 装填）

### [Fix] 持弩单击无反应
